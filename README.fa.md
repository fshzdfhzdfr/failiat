# ربات گفت‌وگوی گیم تلگرام

ربات برای گروه عمومی `@Pixel_Mediair` تنظیم شده است. اگر به مدت ۱۵ دقیقه هیچ پیام انسانی نرسد، با کمک هوش مصنوعی بحث یا چالش کوتاهی درباره بازی‌های رایانه‌ای شروع می‌کند. ربات پیام‌های گروه را به مدل می‌فرستد تا تشخیص دهد آیا پاسخ مرتبطی لازم است؛ پاسخ‌ها کوتاه و فارسی هستند. پیام‌های نامرتبط معمولاً بی‌پاسخ می‌مانند.

## راه‌اندازی محلی

نیازمند Python 3.11 یا جدیدتر است.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

مقادیر فایل `.env` را کامل کنید و سپس:

```bash
set -a; source .env; set +a
python bot.py
```

## استقرار در Railway

۱. پوشه پروژه را به یک مخزن خصوصی GitHub اضافه و به Railway متصل کنید، یا آن را از Railway با روش دلخواه خودتان وارد کنید.
۲. Railway به کمک `railway.json` پروژه را می‌سازد و فرمان `python bot.py` را به‌عنوان سرویس دائمی اجرا می‌کند.
۳. در بخش **Variables** سرویس Railway این متغیرها را اضافه کنید:

- `TELEGRAM_BOT_TOKEN`: توکن ساخته‌شده توسط `@BotFather`
- `FREEMODEL_API_KEY`: کلید API از داشبورد FreeModel
- `ALLOWED_CHAT_USERNAME`: مقدار `Pixel_Mediair`
- `QUIET_MINUTES`: مقدار `15`
- `REPLY_COOLDOWN_SECONDS`: مقدار پیش‌فرض `20` بین پاسخ‌های معمولی؛ اشاره یا پاسخ مستقیم به ربات از این محدودیت عبور می‌کند.
- `FREEMODEL_MODEL`: به‌طور پیش‌فرض `gemini-3.7-flash`؛ در صورت نبودن آن در حساب، شناسهٔ مدلی را بگذارید که در FreeModel فعال است.

کلیدها را در Git، کد، لاگ یا چت قرار ندهید. فقط در Variables سرویس Railway وارد کنید. این برنامه به پورت HTTP نیاز ندارد و با polling کار می‌کند.

## تنظیم تلگرام

- ربات را با `@BotFather` بسازید و به گروه اضافه کنید.
- برای دریافت متن‌های عادی گروه، Privacy Mode ربات را در BotFather خاموش کنید؛ روش دیگر، مدیرکردن ربات در گروه است. برای پاسخ و شروع بحث، مجوز ارسال پیام کافی است.
- نام کاربری گروه باید عمومی و برابر `@Pixel_Mediair` باشد. اگر گروه خصوصی است یا نام کاربری‌اش عوض شد، باید به‌جای نام کاربری از شناسهٔ عددی گروه استفاده شود و کد/تنظیمات تغییر کند.
- اگر از webhook قبلاً برای همین توکن استفاده شده، راه‌اندازی polling ممکن است webhook را پاک کند؛ در یک توکن نباید هم‌زمان webhook و polling فعال باشند.

## رفتار و حریم خصوصی

فقط متن گروه مجاز پردازش می‌شود. تاریخچهٔ کوتاهی از پیام‌ها فقط در حافظهٔ همان فرایند نگه‌داری می‌شود و با راه‌اندازی مجدد پاک می‌شود. پیام‌های متنی برای تولید پاسخ به FreeModel ارسال می‌شوند. برای محتوای حساس، پیش از استفاده از API خارجی این موضوع را به اعضای گروه اطلاع دهید.

مدل دربارهٔ پیام‌های متنی تصمیم می‌گیرد که پاسخ گیمی لازم است یا نه؛ پاسخ‌های معمولی حداقل ۲۰ ثانیه فاصله دارند، اما اشاره یا پاسخ مستقیم به ربات از این محدودیت عبور می‌کند. پیام‌های غیرمتنی تایمر سکوت را از نو تنظیم می‌کنند ولی به مدل فرستاده نمی‌شوند.
